## Пример заполнения (сокращённый)

```markdown
# Фильтр просроченных задач

## Простыми словами
В списке задач появится кнопка «Просроченные». По нажатию на неё останутся видны только задачи, у которых прошёл срок, но они ещё не выполнены. Выбор запоминается — после перезагрузки страницы снова откроется тот же фильтр.

## Контекст
Сейчас подсветка просроченных есть, но отдельного фильтра нет — пользователь не может показать только просроченные.

## Цель
Добавить фильтр «просроченные» рядом с существующими фильтрами статуса.

## Требования
1. В UI рядом с фильтрами all/active/done появляется фильтр «overdue».
2. Фильтр показывает задачи с due < текущей даты и done = false.
3. Выбранный фильтр сохраняется при перезагрузке страницы (localStorage).

## Затронутые файлы
| Файл | Изменение |
|------|-----------|
| apps/frontend/index.html | фильтр-кнопка + логика фильтрации computed |

## API / БД
Не требуется — фильтрация только на клиенте, данные уже приходят через GET /api/todos.

## Критерии приёмки
- [ ] Создать задачу с вчерашним дедлайном через API, убедиться что она видна в фильтре overdue
- [ ] Выполненная задача с вчерашним дедлайном НЕ видна в overdue
- [ ] После перезагрузки фильтр остаётся выбранным

## Деплой
`./deploy.sh` после правок index.html.
```
